# Competitive Programming Knowledge Base (CPKB)

![CPKB TUI Gallery](https://raw.githubusercontent.com/Aaravshah2907/cpkb/main/intro-image.png)

CPKB is a local, terminal-first knowledge base for competitive programming snippets, algorithms, and tricks. It is built as a **high-performance native Rust binary** backed by SQLite — no Python runtime required for the core TUI or CLI.

## Version 3.0 Features

- **Rust-native TUI**: Blazing-fast ratatui terminal UI — no Python, no virtual environments.
- **Store snippets**: Add code snippets with title, description, use-case, tags, and language.
- **Full-text search**: Real-time search across titles, descriptions, tags, and code.
- **Track usage**: Record every time you use a snippet in a problem, with optional notes.
- **Sort & filter**: Sort by date, snippet ID (natural sort), or name. Filter by language or tag.
- **Custom themes**: Choose from built-in themes (Nord, Dracula, Gruvbox, Catppuccin Mocha, Cosmere, Scadrial…) or define your own 11-color hex palette in the TUI.
- **Layout control**: Toggle horizontal / vertical pane layout and border styles from the Settings modal.
- **Deterministic ID colors**: Each snippet ID prefix gets a distinct, consistent color from the Cosmere/Scadrial palette.
- **Rich language badges**: Language-specific colored badges in the snippet list.
- **Flexible ID formats**: Configurable prefix + digit patterns per project (e.g. `ALG_####`, `NOTE-###`).
- **Export**: Export to Markdown, JSON, or HTML.
- **Shell completions**: Bash, Zsh, and Fish completions generated by the binary.
- **XDG Base Directory compliant**: Data lives in `~/.local/share/cpkb/`.

> **Python legacy TUI** (`cpkb-py`) is still available as an optional install for users who relied on the Textual-based interface. See [Legacy Python TUI](#legacy-python-tui) below.

## Installation

### Homebrew (macOS & Linux) — Recommended

```bash
brew tap Aaravshah2907/cpkb
brew install Aaravshah2907/cpkb/cpkb
```

The formula compiles the Rust binary from source — no Python needed.

### From Source (Rust)

```bash
git clone https://github.com/Aaravshah2907/cpkb.git
cd cpkb
cargo install --path rust
```

### Quick installer script

```bash
git clone https://github.com/Aaravshah2907/cpkb.git
cd cpkb
sh setup.sh
```

The script builds and installs the Rust binary into `~/.cargo/bin/cpkb` and writes an initial `config.json`.

### Pre-built binaries

Download a pre-built binary for your platform from the [GitHub Releases](https://github.com/Aaravshah2907/cpkb/releases) page:

| Platform | File |
|---|---|
| macOS (Apple Silicon) | `cpkb-macos-arm64.tar.gz` |
| macOS (Intel) | `cpkb-macos-x86_64.tar.gz` |
| Linux (x86_64) | `cpkb-linux-x86_64.tar.gz` |

Extract and place `cpkb` anywhere on your `$PATH`.

## Quick Start

```bash
# Launch the TUI
cpkb tui

# Add a snippet non-interactively
cpkb add --title "Binary Search" --language cpp

# List snippets, sorted by name
cpkb list --sort name

# Search
cpkb search "segment tree"

# Copy snippet code to clipboard
cpkb copy CP0042

# Export to markdown
cpkb export
```

## TUI Keybindings

| Key | Action |
|-----|--------|
| `j` / `k` or `↑`/`↓` | Navigate list |
| `Enter` | View snippet detail |
| `/` | Search / filter |
| `a` | Add new snippet |
| `e` | Edit selected snippet |
| `d` | Delete selected snippet |
| `o` | Cycle sort order (date → ID → name) |
| `[` / `]` | Resize left pane |
| `s` | Open Settings modal |
| `?` | Help |
| `q` / `Ctrl+C` | Quit |

### Settings Modal (`s`)

- **Theme** — switch between built-in themes
- **Language** — set default language for new snippets
- **Sort** — change default sort order
- **Layout** — toggle horizontal / vertical
- **Border style** — rounded / solid / double / thick
- **Custom theme** (`c`) — open the hex color editor for all 11 palette slots

## CLI Reference

### Core Commands

```bash
cpkb add                   # Add snippet interactively
cpkb add --id-format <fmt> # Use a named ID format
cpkb list                  # List all snippets
cpkb list --sort id        # Sort by ID (natural)
cpkb list --sort name      # Sort alphabetically
cpkb show <id>             # Show snippet details + usages
cpkb search <query>        # Full-text search
cpkb edit <id>             # Edit snippet in $EDITOR
cpkb delete <id>           # Delete snippet
cpkb copy <id>             # Copy code to clipboard
cpkb recent                # Last 10 snippets added
cpkb random                # Random snippet for review
cpkb stats                 # Database statistics
```

### Usage Tracking

```bash
cpkb use <id> <file>       # Record usage in a file
cpkb usages <id>           # List all usages
cpkb edit-usage <id>       # Edit a usage record
```

### Import / Export

```bash
cpkb export                           # Export to Markdown
cpkb export --format json             # Export to JSON
cpkb export --format html             # Export to HTML
cpkb import <file>                    # Import from db/json/md/html
cpkb import --defaults                # Import bundled C++ cheatsheets
cpkb import --list-defaults           # Preview bundled cheatsheets
cpkb backup                           # Manual database backup
```

### ID Formats

```bash
cpkb id-format list                   # Show configured formats
cpkb id-format add algo --pattern "ALG_####"
cpkb id-format add note --pattern "NOTE-###" --default
cpkb id-format default algo
```

Patterns use `#` for digits. Example: `NOTE-###` → `NOTE-001`, `NOTE-002`, …

### TUI

```bash
cpkb tui                   # Launch interactive TUI
```

## Configuration

Config is stored at `~/.local/share/cpkb/config.json`. Key fields:

```json
{
  "default_language": "cpp",
  "display": {
    "theme": "nord",
    "layout": "horizontal",
    "border_style": "round",
    "sort_by": "date",
    "accent_color": "cyan",
    "left_pane_width": 30
  },
  "snippets": {
    "max_number": 9999,
    "id_formats": {
      "default": { "prefix": "CP", "digits": 4, "separator": "", "uppercase": true }
    }
  },
  "backups": { "max_backups": 25, "backup_on_exit": true }
}
```

Available themes: `nord`, `dracula`, `gruvbox`, `catppuccin-mocha`, `catppuccin-latte`, `tokyonight`, `onedark`, `solarized-dark`, `cosmere`, `scadrial`, `custom`.

## Requirements

**Runtime**: None — the Rust binary is statically linked.

**Optional**:
- `fzf` for `cpkb fzf`
- `pbcopy` / `xclip` / `xsel` / `clip` for clipboard commands
- Python 3.11+ only if you use the legacy TUI

**Build from source**: Rust toolchain (`cargo`) — install from [rustup.rs](https://rustup.rs/)
