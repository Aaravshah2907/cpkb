# Competitive Programming Knowledge Base (CPKB)

![CPKB TUI Gallery](https://raw.githubusercontent.com/Aaravshah2907/cpkb/main/intro-image.png)

**CPKB v3** is a local, terminal-first knowledge base for competitive programming snippets, algorithms, and tricks — built as a **high-performance native Rust binary** backed by SQLite. No Python, no virtual environments, no dependencies at runtime.

---

## Features

- 🦀 **Rust-native TUI** — blazing-fast [`ratatui`](https://ratatui.rs/) interface, zero Python required
- 🔍 **Full-text search** — real-time across titles, descriptions, tags, and code
- 🎨 **Rich themes** — Nord, Dracula, Gruvbox, Catppuccin Mocha, Cosmere, Scadrial, and custom 11-color hex palettes
- 🌈 **Deterministic ID colors** — each snippet ID prefix gets a unique, consistent color
- 🏷️ **Language badges** — colored per-language icons in the snippet list
- 📐 **Flexible layout** — toggle horizontal / vertical panes, 4 border styles, resizable panes
- 🔢 **Sort & filter** — sort by date, ID (natural sort), or name; filter by tag or language
- 📦 **Export** — Markdown, JSON, HTML, raw SQLite database
- 📥 **Import** — from Markdown, JSON, HTML, or SQLite exports; bundled C++ cheatsheets included
- ♻️ **Spaced repetition** — SM-2 algorithm for snippet review (`revise` / `srs-stats`)
- 🔑 **Flexible ID formats** — configurable prefix + digit patterns per project (`ALG_####`, `NOTE-###`)
- 🐚 **Shell completions** — Bash, Zsh, Fish, PowerShell, Elvish (generated by the binary)
- 📁 **XDG compliant** — all data lives in `~/.local/share/cpkb/`

> **Legacy Python TUI** (`cpkb-py`) is still available as an optional install — see [Legacy Python TUI](#legacy-python-tui).

## Installation

### Homebrew (macOS & Linux) — Recommended

```bash
brew tap Aaravshah2907/cpkb
brew install Aaravshah2907/cpkb/cpkb
```

The formula compiles the Rust binary from source — no Python needed.

### Pre-built binaries

Download from the [Releases page](https://github.com/Aaravshah2907/cpkb/releases):

| Platform | File |
|---|---|
| macOS (Apple Silicon) | `cpkb-macos-arm64.tar.gz` |
| macOS (Intel) | `cpkb-macos-x86_64.tar.gz` |
| Linux (x86_64) | `cpkb-linux-x86_64.tar.gz` |

Extract and place `cpkb` anywhere on your `$PATH`.

### From Source (Rust)

```bash
git clone https://github.com/Aaravshah2907/cpkb.git
cd cpkb
cargo install --path rust
```

### Quick installer script

```bash
git clone https://github.com/Aaravshah2907/cpkb.git
cd cpkb
sh setup.sh
```

Builds and installs to `~/.cargo/bin/cpkb`, writes an initial `config.json`, and optionally imports bundled C++ cheatsheets.

## Shell Completions

```bash
# Automatic (detects active shell and installs completion script):
cpkb install-completions

# Or manual generation:
# Zsh
cpkb completions zsh >> ~/.zshrc && source ~/.zshrc

# Bash
cpkb completions bash >> ~/.bashrc && source ~/.bashrc

# Fish
cpkb completions fish > ~/.config/fish/completions/cpkb.fish
```

Homebrew manages completions automatically at install time.

## Quick Start

```bash
cpkb tui                        # Launch the TUI
cpkb add                        # Add a snippet interactively
cpkb list                       # List all snippets (sorted by date)
cpkb list --sort name           # Sort alphabetically
cpkb list --sort id             # Sort by ID (natural: CP2 < CP10)
cpkb list --json                # Output JSON array for scripting
cpkb search "segment tree"      # Full-text search
cpkb search "tree" --json       # Search with JSON output
cpkb show CP0042                # View a snippet's details and usages
cpkb show CP0042 --json         # View snippet as JSON
cpkb query                      # Pipeline-friendly ID | Title rows (supports fzf)
cpkb copy CP0042                # Copy code to clipboard
cpkb export                     # Export to Markdown
cpkb stats                      # Database statistics
```

## TUI Reference

Launch with `cpkb tui`.

### Navigation & Actions

| Key | Action |
|-----|--------|
| `j` / `k` or `↑` / `↓` | Navigate snippet list |
| `Enter` | View snippet detail / code |
| `/` | Live search / fuzzy filter |
| `y` / `c` | **Quick Yank / Copy** selected code to clipboard |
| `L` | **Cycle language filter** (`All` → `cpp` → `python` → `rust` → …) |
| `t` | **Open Tag selector modal** to filter by specific tag |
| `a` | Add new snippet (modal form / `$EDITOR`) |
| `e` | Edit selected snippet (modal form / `$EDITOR`) |
| `Ctrl+e` | Directly open selected snippet in `$EDITOR` |
| `d` | Delete selected snippet (confirm prompt) |
| `o` | Cycle sort order (date → ID → name) |
| `[` / `]` | Resize left pane narrower / wider |
| `s` / `,` | Open Settings modal |
| `?` | Help overlay |
| `Esc` | Clear search, language & tag filters / close modal |
| `q` / `Ctrl+C` | Quit |

### Settings Modal (`s`)

| Row | Control |
|-----|---------|
| Theme | Cycle built-in themes |
| Language | Set default language for new snippets |
| Sort | Change default sort order |
| Layout | Toggle horizontal ↔ vertical pane layout |
| Border | Cycle border styles (round / solid / double / thick) |
| Custom Theme (`c`) | Open the hex color editor (11 palette slots with live preview) |

## CLI Reference

### Snippet Management

```bash
cpkb add                            # Add snippet interactively
cpkb add --language rust            # Pre-set language
cpkb add --id-format algo           # Use a named ID format
cpkb list                           # List all snippets
cpkb list --sort id                 # Sort by ID (natural sort)
cpkb list --sort name               # Sort alphabetically by title
cpkb list --json                    # Machine-readable JSON array of snippets
cpkb show <id>                      # Show details, code, and usages
cpkb show <id> --json               # Snippet details as JSON object
cpkb search <query>                 # Full-text search (AND across fields)
cpkb search <query> --json          # Search results as JSON array
cpkb query [query]                  # Pipeline-friendly: outputs id | title rows (default: all)
cpkb query [query] --limit <n>      # Limit query result rows
cpkb edit <id>                      # Edit in $EDITOR
cpkb delete <id>                    # Delete permanently
cpkb copy <id>                      # Copy code to clipboard
cpkb copy <id> -f <file>            # Append code to a file
cpkb recent                         # Last 10 snippets added
cpkb random                         # Random snippet for review
cpkb stats                          # Database statistics
cpkb config                         # Show active config and paths
cpkb install-completions            # Auto-detect shell and install completions
```

### Tags

```bash
cpkb tag-add <id> <tag>             # Add a tag to a snippet
cpkb tag-remove <id> <tag>          # Remove a tag
```

### Usage Tracking

```bash
cpkb use <id> <file>                # Record snippet usage in a file/problem
cpkb usages <id>                    # List all recorded usages
cpkb edit-usage <id>                # Edit a usage record in $EDITOR
```

### Import / Export

```bash
cpkb export                         # Export to Markdown (~/.local/share/cpkb/exports/)
cpkb export-json                    # Export to JSON
cpkb export-html                    # Export to styled HTML
cpkb export-db                      # Copy raw SQLite DB to exports/
cpkb import <file>                  # Import from db / json / md / html
cpkb import --defaults              # Import bundled C++ STL cheatsheets
cpkb import --list-defaults         # Preview bundled cheatsheets
cpkb backup                         # Manual timestamped database backup
```

### Spaced Repetition (SM-2)

```bash
cpkb revise                         # Start a revision session — rate recall 0–5
cpkb srs-stats                      # Show retention stats and review schedule
```

### ID Formats

```bash
cpkb id-format list                 # Show configured formats
cpkb id-format add algo --pattern "ALG_####"
cpkb id-format add note --pattern "NOTE-###"
cpkb id-format default algo         # Set default for cpkb add
```

Patterns use `#` for digits. Example: `NOTE-###` → `NOTE-001`, `NOTE-002`, …

## Configuration

Config file: `~/.local/share/cpkb/config.json`

```json
{
  "default_language": "cpp",
  "display": {
    "theme": "nord",
    "layout": "horizontal",
    "border_style": "round",
    "sort_by": "date",
    "accent_color": "cyan",
    "left_pane_width": 30
  },
  "snippets": {
    "max_number": 9999,
    "id_formats": {
      "default": { "prefix": "CP", "digits": 4, "separator": "", "uppercase": true }
    }
  },
  "backups": {
    "max_backups": 25,
    "backup_on_exit": true
  }
}
```

**Available themes:** `nord` · `dracula` · `gruvbox` · `catppuccin-mocha` · `catppuccin-latte` · `tokyonight` · `onedark` · `solarized-dark` · `cosmere` · `scadrial` · `custom`

## Requirements

**Runtime:** None — the Rust binary is self-contained.

**Optional runtime deps:**
- `fzf` for `cpkb fzf`-style fuzzy filtering
- `pbcopy` / `xclip` / `xsel` / `clip` for clipboard commands (`cpkb copy`)
- Python 3.11+ only if using the legacy Python TUI

**Build from source:** Rust toolchain — install from [rustup.rs](https://rustup.rs/)
